    Design notes

    • Focal point: the Next step box answers "what now?" in every state; it gets the pink edge when it needs the user today.
    • Stepper: Applied → Screening → Interviewing → Offer → Accepted as steps; Rejected and Withdrawn sit after "or" as a branch. The select beside it is the manual override (an Event "by you", undoable).
    • Every Event names its cause: by email, by you, or by apply-kit (schedule, source checks).
    • Follow-ups: nudge 7 days after Applied with no reply, thank-you within 24 hours of an interview, check-in 7 days after the last interview with no news, offer note to self after 1 day. A reply or Status change cancels a pending nudge. Never chases twice for the same stage on its own.
    • Package as sent is read-only: CV PDF, cover letter and answers exactly as approved, and where it was submitted.
