Anatomy

  1. Letterhead: name (Geologica 20pt, pine deep), current title, one contact line in body text. Contact details sit in the page body, never in a header or footer region, so parsers read them.
  2. Sections in a fixed order: Summary, Experience, Skills, Education, Languages and courses. Standard headings only; the AI can't rename, add or reorder them.
  3. Experience: reverse-chronological; title · employer, place on the left, dates on the right as real text (months and years). 1–4 bullets, each under 160 characters, starting with a verb.
  4. Skills: one line, separated by " · ". No bars, ratings or icons.

Fixed rules

  1. A4, single column, one page, margins 18mm, body 9.75pt Onest, line height 1.38.
  2. One accent: pine deep on the name and section titles only (8.2:1 on white).
  3. Fonts embedded, ligatures off, real selectable text; no tables, columns, text boxes or images except the optional photo.
  4. Spill onto page 2 is reported, never fixed by shrinking type or margins.
  5. The app theme never touches it: always white paper, also in dark mode.
