# Career review: decisions by period

The review begins with “Where was I, during which period?” before asking the user to check individual extracted facts. Work and education occupy separate vertical rails, newest first, with an expandable card for each suggested period. Narrow screens stack the lanes. The rails indicate chronology, not a shared proportional time scale.

Reuse Vitosha’s palette through shared tokens: ground #edf1ee, surface #ffffff, ink #1d2b25, pine #2c6652 and conflict amber #75561a. Geologica carries headings and dates; Onest carries evidence and controls. Everything is left aligned. Amber identifies differing fields; no decorative chart is needed.

Suggested comparisons use employer tokens and overlapping dates. They deliberately tolerate title and date differences. They do not establish equivalence: promotions, repeated employment, unrelated employers sharing a word and separate study stages can appear together. Manual selection handles missed aliases. A persistent keep-separate decision prevents regrouping, including after another source alias becomes canonical.

A comparison table shows every original version, source and description. Only differing fields receive emphasis. Users can exclude entries before resolving the selected subset. Fields with conflicting values start unselected. The result is a new unconfirmed period, with all descriptions and attached facts retained. Only identical clean facts with compatible classifications consolidate. Conflicts, scans and multiple confirmed copies remain reviewable.

The existing per-piece review controls remain inside each period. A single resolved period offers the existing bulk confirmation path for eligible facts. Original imported entries stay visible as evidence after reconciliation. Undo restores the prior state only if no later edit, import, analysis or review decision would be overwritten.

The AI deduplication panel is secondary and collapsed. Timeline arrangement and manual reconciliation do not send data to AI providers or spend credits.
